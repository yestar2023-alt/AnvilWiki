## What are the official minimum requirements?

The Steam listing currently requires a 64-bit Windows 10 or Windows 11 system. The minimum tier names a 4-core CPU at 3.0 GHz, represented by the Intel Core i5-6500 or AMD Ryzen 3 1200. It also lists 8 GB RAM, a DirectX 11 GPU with 2 GB VRAM, DirectX version 11, and 2 GB of available storage.

The listed graphics examples are Intel UHD 620, GeForce GTX 750 Ti, and Radeon R7 260X. The minimum notes add a specific recommendation: choose "Low" in the graphics settings for a smoother experience. That note comes from the developer and is the most concrete performance guidance currently available.

![Large city map with many entities, representing the game's top-down scale](/images/game/screenshot-1.webp)

## What does the recommended tier add?

The recommended tier keeps the same Windows and DirectX requirements but raises the CPU target to 6 cores at 3.5 GHz, represented by the Intel Core i5-10400 or AMD Ryzen 5 3600. It lists 16 GB RAM and names the GeForce GTX 1050 Ti or Radeon RX 570 as graphics examples. Storage remains 2 GB.

These are component classes, not a promise that every city, custom map, or co-op session will run at the same frame rate. Population density and map design can change the load. If your PC sits between the two tiers, start conservatively and adjust settings based on what you observe.

## Does the game support macOS or Linux?

The Steam app details currently list Windows as the only supported platform. The presskit also lists Windows. Do not assume that a Mac or Linux version exists because a similar strategy game supports those systems. Check the store page again if platform support matters to you.

## What should laptop owners check?

Check the exact GPU model, not just the processor name. A laptop can have a capable CPU and still use integrated graphics, and the minimum list includes Intel UHD 620 as an example. The official Low-setting note is especially relevant for integrated graphics and older mobile chips.

Also confirm 64-bit Windows, available storage, and that the system is not relying on shared memory to meet the VRAM figure. The store page uses hardware examples, so a similarly named laptop model may have a different graphics configuration.

## Do Workshop maps change the performance picture?

Custom maps can vary in scale, object density, and the number of active entities. The official requirements do not define a separate baseline for Workshop content. If a developer-made city runs acceptably but a large custom map does not, the map itself may be the variable.

Before blaming your hardware, test another map and a fresh save. The [maps and Workshop guide](/guides/maps-and-workshop/) explains how to check version and map notes. For co-op, network conditions are separate from hardware performance, so use the [co-op guide](/guides/co-op/) when troubleshooting a session rather than assuming a GPU problem.

## What is the practical buying advice?

If your PC meets only the minimum, expect to use lower graphics settings and avoid assuming high frame rates on the largest scenes. If you are upgrading, the recommended CPU and memory targets are the clearer long-term choice, while the listed GPUs remain modest by current standards.

This is guidance based on the published requirements, not a benchmark of every configuration. Start with the [beginner guide](/guides/beginner-guide/) once the game runs, and change one setting at a time if you need to diagnose performance.
